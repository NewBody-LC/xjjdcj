小鸡舰队出击 - 一键遗迹工具
目录结构说明
================

【便携版目录结构】
win-unpacked/
├── 网页嵌入器.exe          # 主程序（双击运行）
├── config.json             # 配置文件（首次运行自动创建，可手动修改）
├── resources/
│   └── app.asar           # 应用代码（不需要修改）
├── locales/               # 语言文件
└── ...其他dll文件

【重要文件说明】

1. 网页嵌入器.exe
   - 主程序文件，双击即可运行
   - 不需要安装，绿色便携

2. config.json（关键！）
   - 位置：与 网页嵌入器.exe 同级目录
   - 作用：存储所有可配置参数
   - 首次运行：程序会自动创建默认配置文件
   - 修改方法：用记事本打开编辑，保存后重启程序生效

3. 使用说明.txt
   - 使用方法和常见问题解答

【配置文件示例】
config.json 内容示例：
{
  "ruins": {
    "preferredHero": "mage",      # 首选英雄：mage(法师)/archer(射手)/assassin(刺客)/priest(牧师)/warrior(战士)
    "targetDifficulty": 3,         # 目标难度：1-8
    "adventureButton": {           # 冒险活动按钮坐标
      "xPercent": 0.75,
      "yPercent": 0.88
    },
    "heroSelection": {             # 英雄选择坐标
      "mage": { "xPercent": 0.50, "yPercent": 0.50, "name": "法师" }
    }
  }
}

【用户首次使用流程】

1. 解压/复制文件到任意位置
2. 双击运行 网页嵌入器.exe
3. 程序会自动在同级目录创建 config.json
4. 登录游戏，开始使用
5. 如需修改配置，关闭程序后用记事本编辑 config.json
6. 保存后重新运行程序

【注意事项】

- config.json 必须与 网页嵌入器.exe 在同一目录
- 不要把 config.json 放到 resources 文件夹内
- 修改配置前请先关闭程序
- 建议备份 config.json 以防修改错误
