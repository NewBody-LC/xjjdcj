## 五、关键判断点一览

| 判断点 | 函数 | 条件 | 结果 |
|--------|------|------|------|
| 停止请求 | checkStopRequested() | ruinsStopRequested==true | 退出 |
| 目标难度 | checkTargetDifficulty() | 当前>=目标 | 结束探索 |
| 冒险页面 | detectAdventurePage() | brightness>120 && colorVar>500 | 继续 |
| 状态检测 | detectGameStateEnhanced() | 返回状态+置信度 | 分支处理 |
| 可达节点 | findReachableNodes() | hasYellowLine==true | 节点有效 |
| 连续无节点 | - | consecutiveNoNodes>=3 | 结束探索 |
| 战斗超时 | handleBattle() | battleTime>=600000ms | 强制结束 |

## 六、可能出错的地方

### 1. 冒险活动按钮点击失败
- 坐标配置不正确
- 页面未加载完成就点击

### 2. 冒险活动页面检测失败
- 检测算法依赖亮度变化，颜色变化
- 页面过渡动画可能导致误判

### 3. 古代遗迹按钮点击失败
- 按钮不在可见区域（需要滑动）
- 滑动方向/距离不正确

### 4. 状态检测返回"未知"
- 置信度低于65%
- 状态转换验证失败

### 5. 节点可达性判断失败
- hasYellowLine() 检测黄色连接线失败
- 玩家位置检测不准确

### 6. 挑战按钮检测失败
- 按钮未出现在预期位置
- 图像识别超时

## 七、日志关键词定位问题

在控制台日志中搜索以下关键词：

| 关键词 | 含义 |
|--------|------|
| "状态检测（高置信度）" | 状态检测成功 |
| "状态检测（低置信度）" | 状态不确定，可能出错 |
| "选择节点" | 正常选择了节点 |
| "没有可到达的节点" | 节点检测/可达性判断失败 |
| "连续多次没有可到达节点" | 即将结束探索 |
| "检测到挑战按钮" | 挑战按钮检测成功 |
| "未检测到挑战按钮" | 挑战按钮检测失败 |
| "进入战斗状态" | 正在处理战斗 |
| "战斗已结束" | 战斗处理完成 |
