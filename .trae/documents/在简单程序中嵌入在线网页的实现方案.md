# Electron方案：创建独立的网页嵌入应用

## 实现步骤

### 1. 初始化Electron项目
1. 创建项目目录
2. 初始化npm项目
3. 安装Electron依赖

### 2. 编写应用代码
1. 创建主进程文件(`main.js`)
   - 配置应用窗口
   - 设置窗口大小和属性

2. 创建渲染进程文件(`index.html`)
   - 使用iframe嵌入在线网页
   - 配置样式使其全屏显示

3. 配置`package.json`
   - 设置应用名称和版本
   - 配置主入口文件
   - 添加启动和打包脚本

### 3. 打包应用
1. 安装打包工具(`electron-builder`)
2. 配置打包参数
3. 执行打包命令生成独立可执行文件

## 技术说明

- **主进程**：负责创建和管理应用窗口，处理系统级事件
- **渲染进程**：负责显示网页内容，通过iframe嵌入目标在线网页
- **打包**：使用electron-builder将应用打包为可执行文件，包含所有依赖

## 代码示例

### package.json
```json
{
  "name": "web-embed-app",
  "version": "1.0.0",
  "description": "嵌入在线网页的Electron应用",
  "main": "main.js",
  "scripts": {
    "start": "electron .",
    "build": "electron-builder"
  },
  "build": {
    "appId": "com.webembed.app",
    "productName": "网页嵌入器",
    "win": {
      "target": ["nsis", "portable"]
    }
  },
  "devDependencies": {
    "electron": "^28.0.0",
    "electron-builder": "^24.0.0"
  }
}
```

### main.js
```javascript
const { app, BrowserWindow } = require('electron');
const path = require('path');

// 创建窗口函数
function createWindow() {
  // 创建浏览器窗口
  const mainWindow = new BrowserWindow({
    width: 1024,
    height: 768,
    webPreferences: {
      preload: path.join(__dirname, 'preload.js'),
      nodeIntegration: true,
      contextIsolation: false
    }
  });

  // 加载index.html文件
  mainWindow.loadFile('index.html');

  // 打开开发者工具（可选）
  // mainWindow.webContents.openDevTools();
}

// 应用就绪时创建窗口
app.whenReady().then(() => {
  createWindow();

  // macOS特殊处理
  app.on('activate', function () {
    if (BrowserWindow.getAllWindows().length === 0) createWindow();
  });
});

// 关闭所有窗口时退出应用
app.on('window-all-closed', function () {
  if (process.platform !== 'darwin') app.quit();
});
```

### preload.js
```javascript
// 预加载脚本，可用于在渲染进程中安全地访问Node.js API
window.addEventListener('DOMContentLoaded', () => {
  console.log('应用已加载');
});
```

### index.html
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>网页嵌入器</title>
    <style>
        body {
            margin: 0;
            padding: 0;
            overflow: hidden;
        }
        iframe {
            width: 100vw;
            height: 100vh;
            border: none;
        }
    </style>
</head>
<body>
    <!-- 在这里替换为你想要嵌入的在线网页地址 -->
    <iframe src="https://www.example.com"></iframe>
</body>
</html>
```

## 打包步骤

1. 安装依赖：`npm install`
2. 安装打包工具：`npm install --save-dev electron-builder`
3. 执行打包命令：`npm run build`
4. 在`dist`目录中找到生成的可执行文件

## 特点

- **独立性**：打包后为单一可执行文件，无需安装Node.js环境
- **跨平台**：可打包为Windows、macOS和Linux版本
- **功能完整**：支持现代网页功能，如JavaScript、CSS3等
- **可定制**：可根据需要修改窗口大小、网页地址等参数

此方案满足用户需求的独立性要求，打包后无需安装任何环境即可运行。
